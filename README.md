# SmartAuction - AI-Powered Online Auction Platform

## 📌 Project Overview
SmartAuction is a university major project developed by a team of Computer Science students at **VNU University of Engineering and Technology (UET)**. Our goal is to build a secure, transparent, and intelligent bidding environment.

## 🛠 Tech Stack
- **Language:** Java (Core logic, Generics, Reflection, File I/O)
- **Architecture:** Object-Oriented Programming (OOP) with Design Patterns
- **Version Control:** Git & GitHub
- **AI Engine:** Xiaomi MiMo-V2.5 (Proposed Integration)

## 🤖 AI Integration: The Fraud Detection Agent
We are integrating **Xiaomi's MiMo-V2.5** to handle complex "Shill Bidding" detection. 
- **Large Context Utilization:** Leveraging the 1M context window to analyze entire auction history logs.
- **Reasoning Chain:** Using long-chain reasoning to identify coordinated price manipulation between accounts.

## 🚀 Key Features
- **Real-time Bidding:** Synchronized auction system using Observer patterns.
- **AI Listing Assistant:** Automated SEO-friendly description generation for sellers.
- **Integrity Monitor:** AI-driven anomaly detection for bidding logs.
